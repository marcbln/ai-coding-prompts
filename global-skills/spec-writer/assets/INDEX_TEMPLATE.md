# Specification Index

This directory contains the specifications that define what the system SHALL do. Each file
documents one feature or capability in a Requirement/Scenario format, verified against by
its implementation plan and tests.

## Naming Convention

Specs are numbered per date: `YYMMDD-N`, where `YYMMDD` is the creation date and `N` is a
per-day sequence number starting at 1. Files use the format:

```
SPEC__<YYMMDD-N>__<kebab-case-title>.md
```

Example: `SPEC__261016-1__vsf-browser-api.md`.
